🔎 Occlusion-Based Feature Attribution

When the Isolation Forest flags a reading, it returns only a score. SkyGuard then asks a series of "What if I remove this feature?" questions — measuring how much the anomaly score drops when each feature is reset to its local median. A large drop = that feature is causing the anomaly. No SHAP library required — edge-deployable on a Raspberry Pi.
